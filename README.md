# 온투의 연금 계산기

공적연금(공무원·사학연금) · 퇴직급여(교원 퇴직수당·명예퇴직수당 → IRP) · 개인연금(연금저축·IRP)을 합쳐
나이별 연간·월간 수령액과 세금을 계산하는 웹 계산기입니다.

- 하나의 `index.html` 파일로 동작하는 정적 페이지입니다 (서버 없음).
- 입력한 값은 **각자의 브라우저(localStorage)에만 저장**되며, 다른 사람이나 다른 기기와 공유·연동되지 않습니다.
- 계산 결과는 수익률·물가를 일정하다고 가정한 추정치입니다. 실제 지급액과 세금은 공무원연금공단·금융회사·세무 전문가에게 확인하세요.

## 배포
GitHub Pages (Settings → Pages → Branch: `main` / root)
